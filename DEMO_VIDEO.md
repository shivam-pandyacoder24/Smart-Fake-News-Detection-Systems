# NewsGuard demonstration video

**Recording:** [demo/NewsGuard_Demo.webm](demo/NewsGuard_Demo.webm)

This browser walkthrough was recorded from the running Streamlit application after the saved model and TF-IDF vectorizer were loaded. It shows the detector interface, empty-input validation, a sample prediction, the model dashboard, and the methodology/limitations view.

The public Streamlit Community Cloud deployment is a separate owner-authorized step; no live URL is claimed until it is deployed and verified.
